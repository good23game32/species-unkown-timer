Create a countdown, then share the same moment with your friends.
For everyone to hear the same song, the audio must be available online. Easiest: upload a properly licensed audio file named countdown-song.mp3 into this same GitHub repository. If you use a direct audio URL, it must link directly to a playable audio file.
Browsers usually block sound until each friend interacts with the page. Ask everyone to open the link and click Enable sound before the event. Keep the page open and the device awake.
The shared link contains the target moment and song path. Anyone with the link can view it. This is a static website, so it does not synchronize playback or send notifications if someone closes the page.
